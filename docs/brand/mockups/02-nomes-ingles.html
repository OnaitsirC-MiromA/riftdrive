Drive + ponte, em inglês curto

Quatro nomes, todos livres no npm (o comando npx … funciona com o nome puro). Mesma base visual escura em todos, de propósito: aqui a decisão é só o nome — a cara a gente fecha na próxima tela.

Drivebridge
A ponte entre dois Drives.
Compartilhado comigo → meu Drive, ou conta A → conta B.
npx drivebridge

A · Drivebridge — literal, zero ambiguidade

Diz exatamente o que faz; quem lê o nome já entende o produto. Pronúncia fácil em português. Risco: é o mais previsível dos quatro e há produtos de nicho com nomes parecidos (não no npm).

Drivespan
Vence a distância entre dois Drives.
"Span" é o vão da ponte — o trecho que liga uma margem à outra.
npx drivespan

B · Drivespan — técnico, elegante, menos óbvio

Soa a engenharia (vão, extensão, alcance) sem ser frio. Curto, único, fácil de achar no Google. Risco: "span" não é palavra que um brasileiro leigo conheça — o nome precisa do subtítulo na primeira vez.

Driveover
Passa seus arquivos pro outro lado.
Jogo de palavras: "drive over" (atravessar) + copiar "over" para o outro Drive.
npx driveover

C · Driveover — o trocadilho

O mais leve e memorável; dá para brincar na copy ("drive it over"). Risco: em inglês "drive over" também é "atropelar" — um nativo pode sorrir pelo motivo errado. Funciona melhor para público brasileiro.

Crossdrive
Travessia entre Drives.
"Cross" = atravessar; também lembra "cross-account", o caso de duas contas.
npx crossdrive

D · Crossdrive — travessia, conexão

Carrega a ideia de conexão entre contas sem precisar de "ponte". Soa a produto de infraestrutura. Risco: "cross" visualmente puxa para um X (fechar/erro) — o símbolo precisa fugir disso, como no esboço acima.

Trocadilhos que gostei mas já estão tomados no npm (serviriam com sufixo, ex. npx pontoon-drive): driveway (o caminho entre drives · tomado), pontoon (ponte flutuante · tomado), portage (carregar a carga entre duas águas · tomado), gangway (passarela navio–cais · tomado), causeway (tomado).

Minha recomendação  Drivebridge se a prioridade é alguém entender em 1 segundo o que o app faz; Drivespan se a prioridade é soar mais refinado e próprio. Os dois sobrevivem bem a um logotipo sério.
